## 2. 结构图

```
                current_
                   │
                   ▼
  head_  ⇄  [ A ]  ⇄  [ B ]  ⇄  [ C ]  ⇄  tail_
  (哨兵)                                  (哨兵)

  每个结点：
    Node { id, LineBuffer content, prev, next, sentinel }
    LineBuffer { char* data_ → new char[len+1]，以 '\0' 结尾；size_ }
```

- `head_.prev == nullptr`、`tail_.next == nullptr`；两个哨兵永不删除。
- **空文档判据**：`head_.next == &tail_`（此时 `current_ == nullptr`）。
- **空行不是空指针**：空行是 1 字节的空串（`len == 0`），`nullptr` 只出现在哨兵上。
- 行号不存储，需要时按链 O(n) 派生（`LineList::rowOf`）。

## 3. 四个推演问题的答案

初始文本 A、B、C 三行，当前行为 B（第 2 行）。

### ① 连续删除三次，分别剩余哪些行，当前行是谁？

| 次数 | 删除前保留的信息 | 删除后剩余 | 新当前行 | 依据 |
| --- | --- | --- | --- | --- |
| 第 1 次 | `next = C`（非哨兵）、`prev = A` | A、C | **C**（优先下一行） | 规则 2 |
| 第 2 次 | `next = 尾哨兵`、`prev = A` | A | **A**（无下一行 → 上一行） | 规则 2 |
| 第 3 次 | `next`、`prev` 都是哨兵 | 空 | **无当前行** | 规则 2 |

结论：剩余 A、C → A → 空；当前行 C → A → 无。
**实测一致**：用例 `T03-01`（`g 2` → `d` → `d` → `d`，逐次核对 `当前行：` 与 `p` 的 `*` 位置）。

### ② 文档删空后，再执行下一行、删除、插入 X，各会发生什么？

| 操作 | 结果 |
| --- | --- |
| 下一行 `n` | 空文档没有当前行 → 输出 `错误：空文档没有当前行`，文档仍为空、仍无当前行 |
| 删除 `d` | 同上，报错且状态不变（不会"删掉哨兵"） |
| 插入 X | 空文档允许插入：创建第一个数据结点，**成为第一行并成为当前行** → 输出 `当前行：1` |

依据：规则 1（空文档没有当前行；上一行/下一行/首行/末行/指定行/删除/替换均应提示并保持空文档状态；插入可创建第一行）。
**实测一致**：`T02-02`（`d` → `i X`）、`T01-01..09`。

### ③ 删除结点之前，要先保留哪些信息？哪些内存由谁释放？

**必须先保留：**

1. 被删结点的 `next` 与 `prev`——改链要用，而且直接决定「新当前行是谁」；
2. 若要展示操作前的图形/历史，还要在**观察者内部复制**被删内容（本阶段可视化未启用，因此不复制，避免无谓开销）；
3. 绝不能保留指向该结点的裸指针：改链后它必须失效；如果 `current` 正指向它，**必须先置空再释放**，否则就是悬垂指针。

**内存由谁释放：**

- 行内容 `char[]`：由 `~LineBuffer` 用 `delete[]` 释放；
- 结点本身：由 `LineList::remove` 中的 `delete node` 释放；
- 两者都随「删除」这一次操作完成，调用方不手动 `delete`。

**顺序**：先改链（让结点不可达）→ 再释放（析构释放内容 + 结点）。代码位置：`src/line_list.cpp` 的 `LineList::remove`、`src/editor.cpp` 的 `Editor::removeCurrent`。

### ④ 你设计的链表在每次操作后，必须保持哪些关系？至少写两条。

- **I1 链接互指一致**：对链上任意结点 p，`p->next->prev == p` 且 `p->prev->next == p`；`head_.prev == nullptr`、`tail_.next == nullptr`。
- **I2 内容合法**：数据结点的行内容不含换行符；空行是 1 字节空串，不是 `nullptr`。
- **I3 当前行合法**：`current == nullptr` ⇔ 链上没有数据结点；否则 `current` 必是链上的数据结点（任何时刻都不指向已释放内存）。
- **I4 链无环可遍历**：数据结点只经 `next` 链可达，从 `head_.next` 走到 `tail_` 恰好经过全部数据结点。
