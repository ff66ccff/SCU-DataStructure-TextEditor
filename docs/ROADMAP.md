## 1. 范围切分

### P0 · 必做（覆盖 100 分）
1. 行级双向链表 + 当前行状态；行内容为自管理 char 数组（new[]/delete[]），**不得用 vector/list 代替行链表**，也不得用固定长度数组截断长行。
2. 基础命令：显示 / 定位（首行、末行、上一行、下一行、指定行号）/ 插入 / 删除 / 替换整行 / 查找子串 / 替换子串 / 统计 / 重新读入 / 保存 / 帮助(h,H) / 退出。
3. 命令行 editor input.txt output.txt；参数缺失或输入打不开要给出原因，**不得当成空文件**。
4. 边界与内存正确性：T01-T14 全通过；内存维度由 A11（分配/释放配平 + 长行往返无截断）判定，无泄漏、无静默截断。
5. 测试材料 + 个人过程记录 + 实验报告。

### P1 · 选做（单独展示，不加基础分）
6. 链表变化可视化：C++ 输出真实状态快照 → HTML + shadcn 风格页面回放。

### 明确不做
- 基础程序里加 GUI / 中文 / 高亮 / 撤销；扩展命令不得改变基础命令语义（指导书 §二 首段）。

## 4. 三份先冻结的契约

实现开始前只冻结这三样，其余细节边写边定。

### 4.1 数据与内存契约（依据 analysis_core §2-§4）

| # | 契约 | 值 |
| --- | --- | --- |
| C1 | 链表形态 | 双向链表 + 头哨兵 + 尾哨兵；空文档判据 head->next == tail |
| C2 | 当前行 | Node* current；行号仅在显示/归档时按链 O(n) 派生，**不存行号** |
| C3 | 行内容 | 每结点独占一份 new char[]，'\0' 结尾，内容不含换行符；空行 = 1 字节的空串，**不是 nullptr**；nullptr 只允许出现在哨兵 |
| C4 | 替换策略 | 一律「先分配新数组 → 拷贝 → 成功后再释放旧数组」；不 realloc、不做原地缩容、等长也走同一路径 |
| C5 | 删除顺序 | 复制（供 trace）→ 改链 → 释放内容 → 释放结点；**不可换序** |
| C6 | 统计 | 不缓存行数/字符数，命令时重算 |
| C7 | 换行 | 读接受 LF 与 CRLF，行结束标记不入结点；写统一 '\n' |
| C8 | 不变式 | I1 链接互指一致；I2 内容非空且无换行；I3 current 合法；I4 链无环可遍历（analysis_core §4.4） |
| C9 | 哨兵选择口径 | 双哨兵是**本人**的选择，不要求组内三人一致（指导书要求每人说明自己的选择） |

**跨文档冲突已关闭（审计 F7 修正）**：analysis_core 主张不维护 capacity，analysis_viz 协议里有 node.capacity。审计证明我原先的调和方案**语义空转**：C4 与 Q3 已锁定「精确分配 newLen+1」，故 capacity 恒等于 len+1，是 len 的纯函数，**无法证明发生过重新分配**（真正的证据是 content_rev 与 content_changed 事件）；且该字段不受 I1-I4 与任何 A 断言守护。**决议：协议中删除 node.capacity 字段**，core 的「不维护 capacity」保持不变，跨文档冲突归零；[docs/analysis_viz.md](analysis_viz.md) 顶部已加勘误说明。

### 4.2 命令契约（依据 analysis_core §7）

| 命令 | 语义 | 改链 | 重分配内容 |
| --- | --- | --- | --- |
| h / H | 列出全部命令及含义 | 否 | 否 |
| p | 显示全部文本、行号、当前行标记 | 否 | 否 |
| n / u | 下一行 / 上一行 | 否 | 否 |
| f / l | 首行 / 末行 | 否 | 否 |
| g 行号 | 定位指定行（1 起） | 否 | 否 |
| i 文本 | 在当前行之后插入，新行为当前行 | 是 | 是 |
| d | 删除当前行 | 是 | 是（释放） |
| r 文本 | 替换整行（可为空） | 否 | 是 |
| / 子串 | 从当前行第 1 列向后查找，返回行号+列号 | 否（命中才改 current） | 否 |
| s /old/new/ | 当前行内替换全部不重叠匹配 | 否 | 是（命中时） |
| c | 统计行数与字符数 | 否 | 否 |
| e | 重新读入**输入文件**（成功后：非空 → current = 首结点；空 → current = nullptr） | 是（整表重建） | 是 |
| w | 保存到**输出文件** | 否 | 否 |
| q | 退出（未保存需确认） | 是（全释放） | 是 |
| x（扩展） | 导出当前真实链表快照：追踪开启时追加 snapshot step；追踪关闭时覆盖写默认位置的单步 trace.ndjson | 否 | 否 |

通用兜底：非法命令、非法行号、越界移动 → 提示原因 + 保持原文本与当前行状态。
扩展纪律：x（及后续扩展）只新增字符，若冲突则换字符；不改写基础命令含义。

**参数文法与错误处理（审计 F12-F15 补齐，随契约冻结）**

| 位置 | 规则 | 非法输入的处理 |
| --- | --- | --- |
| i / r 的文本 | 取命令字符之后到行尾的全部剩余内容，去掉分隔用的**一个**前导空格，保留内部空格；只敲命令字符即空串 | 空串合法（插入/替换为空行） |
| / 的查找串 | 查找串**不能为空**（指导书 §二 第 4 条） | 命令后无内容 → 提示非法，状态不变 |
| s 的分隔符 | 严格 s /old/new/：恰好两个 /，old 非空、new 可空；不支持转义；old 与 new 内不得含 / | 缺结尾 /、多于两个 /、old 为空 → 提示非法，状态不变 |
| 未保存确认 | 交互为 y/n（y = 放弃修改继续，n = 取消） | 其它输入视为取消 |
| x 扩展命令 | 导出当前链表快照 NDJSON；追踪开启时追加到当前 trace，关闭时写输出文件同目录 trace.ndjson，**覆盖写** | 打不开 → 提示失败并保持基础状态不变 |

h/H 的帮助文本必须逐条说明上述文法（提交前自查要求「所有基础命令及参数含义可以通过 h 或 H 查询」）。

### 4.3 快照协议 v1.0（依据 analysis_viz §3，冻结版本号）

- 文件 trace.ndjson：NDJSON，第 1 行 meta，其后每行一条 step，**每步自带全量 nodes 数组** + changed 变更摘要 + checks 自检。
- 关键字段：node.id（全局单调、永不复用、哨兵共用计数器）、node.kind/side、node.row/ordinal、node.text/len/content_rev、node.prev/next（null 表示空指针）、node.is_current；step.op/op_zh/seq/ok/error/current/current_row/doc（含 doc.empty_doc / doc.data_nodes）/changed/checks。**node.capacity 依审计 F7 决议删除。**
- 前端纪律：只按 next 走链渲染，**禁止按 id 或行号排序**；并用自校验（走链序 == 按 ordinal 的 data 序 == doc.data_nodes）证明不是「拼出来的链」。
- C++ 侧纪律：trace 只读、const、单点上报；--trace 缺省关闭，关闭时编辑逻辑零分支差异，且关闭路径纳入 T01-T14 回归。
- 观察者接缝（审计 F8）：删除时的「复制」发生在 **trace 观察者内部**；核心删除路径只在固定点调用一个**可能为空**的观察者（空实现即 no-op），核心代码不含 if(trace) 分支，trace-off 时也不付出多余拷贝。

## 5. 阶段验收标准（可执行断言）

**A1-A9、A11、A12 为基础必做；A10 属选做可视化**（审计 F1 拆分：可视化后移或降级时，A10 不得阻塞基础验收）。

| # | 断言 |
| --- | --- |
| A1 | A/B/C 三行、当前行 B，连续删除三次：剩余 A,C → A → 空；当前行依次为 C → A → 无 |
| A2 | 空文档执行 上/下/首/末/指定行/删除/替换 → 提示且状态不变；插入 → 建第一行并成为当前行 |
| A3 | 行号 0 / 负数 / 超范围 → 提示且文本与 current 不变；首行按上一行、末行按下一行不环绕 |
| A4 | 替换整行或子串后，显示中当前行标记仍停在同一行号、且该行显示新内容（基础可观察）；「同一结点不变」由 A10 的结点 id 判定 |
| A5 | 查找区分大小写，从当前行第 1 列起向后，不回到文档开头；返回行号+列号（1 起）；命中后该行成为当前行，未命中状态不变；空文档返回未找到 |
| A6 | 替换子串仅作用于当前行、从左到右全部不重叠匹配、新生成内容不再被搜索；old 非空、new 可空；无匹配时文本与 current 逐字节不变（「零分配」归入 A11 判定） |
| A7 | 统计对齐表格 3：空文件 0/0、A 1/1、A+换行 1/1、单换行 1/0、A+两个换行 2/1 |
| A8 | 保存后以输出文件为输入重启，行序列与统计一致；读入接受 LF/CRLF，末尾换行不额外生成结点 |
| A9 | 输入不可读 / 输出不可写 → 明确报错且不报成功；重新读入失败保留原缓冲区；未保存取消则完全保留 |

**基础补充（审计 F2/F3 新增）**

| # | 断言 |
| --- | --- |
| A11 | （内存）固定序列 插入→变长替换→删除→重新读入→退出 结束后「分配次数 == 释放次数」；5000+ 字符行长行保存再读入后 strlen 与记录长度一致、内容逐字节一致 |
| A12 | 启动读入非空文件后 current = 第一行；e 成功后非空 → current = 第一行，空文件 → current = nullptr |

**选做 · 可视化（审计 F1 拆出，不参与基础验收）**
