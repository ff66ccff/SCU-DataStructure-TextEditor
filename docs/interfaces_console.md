## 1. 启动方式

    editor <输入文件> <输出文件> [--trace [路径] | --trace=off] [--trace-buffer]

## 2. 退出码

| 码 | 含义 |
| --- | --- |
| 0 | 正常退出（收到 q，或 stdin EOF） |
| 2 | 必需参数缺失，或可选启动参数无法识别 |
| 3 | 输入文件不可用（无法打开，或打开后读取失败）。两种情形提示文案不同，退出码相同 |
| 4 | 保留：启动时输出路径不可写（运行期 `w` 失败由命令提示，不使用此退出码） |
| 5 | 程序退出时自有 `char[]` 或数据结点的分配/释放计数不平衡 |

## 3. 启动校验顺序（严格按序）

1. 缺少输入/输出文件，或可选参数不是 `--trace [路径]`、`--trace=off`、`--trace-buffer` → 向 **stderr** 输出用法并以退出码 **2** 结束：

       用法：editor <输入文件> <输出文件> [--trace [路径] | --trace=off] [--trace-buffer]

   随后以退出码 **2** 结束。**不得**进入编辑器。
2. 输入文件不可用（不存在、无权限、是目录；或打开后读取失败）→ 向 **stderr** 输出一行：

       错误：无法打开输入文件：<路径原样>

   随后以退出码 **3** 结束。**不得**把它当作空文件，**不得**进入编辑器主循环。

   因「打开后读取失败」也返回退出码 3，此种情形（少见）输出另一条文案：

       错误：读取输入文件失败：<路径原样>

   内存不足时输出 `错误：内存不足，无法读入输入文件：<路径原样>`，仍返回退出码 3。

3. 成功读入 → 向 **stdout** 依次输出两行摘要：

       已读入 <行数> 行，<字符数> 个字符
       当前行：<行号>        （非空文档，按 A12 取第一行）

   空文档时第二行为：

       当前行：无

   计数口径同指导书表格 3：行数 = 数据结点数；字符数 = 各行内容长度之和（不含行结束标记）。

## 4. 提示符

每次读命令前向 stdout 输出提示符 `> `（两个字符：大于号 + 空格），并 flush。**不换行**。

## 5. 命令文法（D2-D11 冻结）

D1 的「去掉首尾空白后整串精确匹配」规则**自 D2 起由本节取代**。新文法下 `q x`、`p x`、`h xyz`、`qq` 仍然是「未知命令」。

**解析步骤（严格按序，对每一行输入）**

1. 若行尾是 `\r`（CRLF 输入残留），先去掉这**一个** `\r`。
2. 跳过行首空白（空格、`\t`）；若已到行尾 → **空行**，忽略（不输出、不退出）。
3. 第一个非空白字符 = **命令字符**；其后的全部字符 = **参数区**（保留内部与行尾空格）。
4. 按命令字符分派：

| 命令字符 | 参数规则 | 类别 |
| --- | --- | --- |
| `p` `h` `H` `q` `f` `l` `n` `u` `d` `c` `e` `w` `x` | 参数区必须**只含空白**，否则整行按未知命令处理 | 无参命令 |
| `g` | 参数区去掉首尾空白后按十进制整数解析（见 §10.4） | 带参 |
| `i` `r` | 参数 = 参数区去掉**恰好一个**前导空格；其余原样保留（含内部空格与行尾空格）。**只有 U+0020 算分隔符**，制表符不算、会被保留在文本里 | 带参 |
| `/` | 查找串 = 参数区去掉恰好一个前导空格；查找串不能为空（§15） | 带参 |
| `s` | 严格使用 `s /旧串/新串/`，不支持 `/` 转义（§16） | 带参 |
| 其它任意字符 | — | 未知命令 |

5. **未知命令**：stdout 输出一行 `未知命令：<原样输入>（输入 h 查看帮助）`，状态不变、不退出。
   `<原样输入>` = 去掉行尾 `\r` 后的**整行原文**（保留首尾空白，见 §12）。

## 6. `p` 的显示格式

每个数据结点一行，格式（注意标记位 1 字符 + 空格 + 行号右对齐宽 4 + 空格 + 竖线 + 空格 + 内容）：

    <标记><空格><行号宽4> | <内容>

- 标记：当前行输出 `*`，其它行输出一个空格。
- 行号从 1 开始，按链表顺序。
- 内容原样输出，不含行结束标记。
- **分隔符 \` | \` 前后各有一个空格，且固定保留**：空行渲染为 \`     2 | \`（竖线后有一个空格，行尾无其他字符）。

非空示例（A/B/C 三行，当前行第 1 行）：

    *    1 | A
         2 | B
         3 | C

空文档输出一行：

    （空文档：没有结点，没有当前行）

## 7. `h`/`H` 帮助内容（必须包含）

措辞可润色，但以下要点**必须逐条出现**（验收按关键词检查）：

1. 用法：`editor <输入文件> <输出文件>`
2. `p` —— 显示全部文本，标出当前行
3. `h` / `H` —— 显示本帮助
4. `q` —— 退出
5. `f` / `l` —— 定位到第一行 / 最后一行
6. `n` / `u` —— 定位到下一行 / 上一行
7. `g <行号>` —— 定位到指定行（行号从 1 起）
8. `i <文本>` —— 在当前行之后插入一行，新行成为当前行；空文档中插入第一行
9. `d` —— 删除当前行，并说明删除后新当前行的选择规则（下一行 → 上一行 → 无）
10. `r <文本>` —— 替换当前行的内容（可为空行），当前行不变
11. `/ <子串>` —— 从当前行开始向后查找，说明返回行号与列号、区分大小写
12. `s /旧串/新串/` —— 当前行内全部不重叠匹配；旧串非空、新串可空
13. `c` / `e` / `w` —— 统计、重新读入输入文件、保存到输出文件
14. `x` —— 导出当前真实链表快照（NDJSON）
15. 一行文法说明：`i`/`r` 与 `/` 去掉一个分隔空格；`s` 严格使用斜杠格式且不支持转义；`g` 使用十进制整数；无参命令之后不得再跟其它字符
16. 一行说明：有未保存修改时 `e` 与 `q` 需要小写 `y` 确认；空行会忽略，未知命令会提示并继续
17. 可视化用法：`--trace [路径]` 开启记录，`--trace-buffer` 关闭逐步 flush，`--trace=off` 关闭；可用浏览器打开 `viz/index.html` 离线回放

## 8. 边界约定（记录 D1 简化规则；D8 已补齐）

- 当前实现接受 LF、CRLF 与单独 CR，行结束标记不进入结点内容；CRLF 只结束一行。
- 每遇一个行结束标记就提交一行（因此单个换行符文件是一行空行）；EOF 只在自上个行结束标记以来读到过字节时提交尾行。
- 空文件为 0 行；`A\n` 为 1 行；末尾换行不额外生成空行。
- 保存以二进制模式写入，统一使用 LF；每个数据结点后写一个 LF，空文档写 0 字节。
- 分配/释放计数在 D7 落地，见 §20。

## 9. 编码约定（D1 实测补充）

- stdout / stderr 一律输出 **UTF-8** 字节；程序启动时把 Windows 控制台输出代码页切到 UTF-8（`src/platform.cpp`），否则中文帮助/提示在真控制台显示为乱码。
- 工程路径与命令行传入的路径均为纯 ASCII：**打开时与显示时都按原样使用**，不做任何代码页转换（2026-10-19 工程目录改名为 `DataStructureEXP` 后，原先的 argv ANSI→UTF-8 转换已删除）。
- 验收脚本读子进程输出时按 UTF-8 解码。
- **行尾**：控制台输出经 CRT 文本模式，重定向到文件时 `\n` 会写成 `\r\n`（Windows 正常行为）。
  逐字节比对前按 CRLF→LF 归一；保存走二进制模式，只写 `\n`（ROADMAP §4.1 C7）。

## 10. 定位命令（D2-D3）

### 10.1 通用约定

- **成功**：`current` 指向目标行，stdout 追加一行 `当前行：<行号>`（行号从 1 起）。
- **失败**：stdout 追加一行 §12 的错误文案；**文本与 current 均不变**（ROADMAP §4.2「通用兜底」）。
- 失败时不输出 `当前行：…` 行。
- 「不环绕」（指导书 规则 / A3）：首行再 `u`、末行再 `n` 均报错，**不得**绕到另一端。

### 10.2 `n` 下一行 / `u` 上一行

| 情形 | 结果 |
| --- | --- |
| 空文档（无当前行） | `错误：空文档没有当前行` |
| `n`，当前行是末行 | `错误：已经是最后一行` |
| `u`，当前行是首行 | `错误：已经是第一行` |
| 其它 | 移动到相邻行，输出 `当前行：<行号>` |

### 10.3 `f` 首行 / `l` 末行

| 情形 | 结果 |
| --- | --- |
| 空文档 | `错误：空文档没有当前行` |
| 非空 | current 置为第一行 / 最后一行，输出 `当前行：<行号>` |

### 10.4 `g <行号>`

- 行号口径：**1 起**，必须落在 `[1, 行数]` 闭区间内。
- 参数按十进制整数解析：允许前导 `-`（负数随后按越界处理），不允许其它字符（`+`、小数点、制表符都不行）；**整串必须被完全消费**。
- 「参数区为空」指**去掉首尾空白后**为空：只敲 `g`、`g` 后跟若干空格或制表符，都算缺参数。

| 情形 | 结果 |
| --- | --- |
| 参数区去空白后为空 | `错误：g 需要一个行号` |
| 不是合法整数（`abc`、`3x`、`1.5`、`+3`、`2 3` 等） | `错误：行号非法：<参数原样>` |
| 整数但 `< 1` 或 `> 行数`（含空文档，此时行数为 0） | `错误：行号超出范围：<n>（当前共 <m> 行）` |
| 语法是整数但**超出 `long long` 可表示范围**（如 `9223372036854775808`，即 2^63；或 1000 位数字串） | 与上一行相同：按**越界**处理，`<n>` 原样回显该数字串 |
| 合法 | 定位并输出 `当前行：<行号>` |

`<参数原样>` = 参数区去掉首尾空白后的字符串。
`<n>` 的回显规则：可解析为 `long long` 时回显其**十进制值**（故 `g -0` 回显 `0`）；溢出的整数串则**原样**回显（保留全部数字）。
`<m>` 为当前行数。

## 11. 插入 / 删除 / 替换整行（D3-D5）

三条命令都依赖「当前行」，空文档一律 `错误：空文档没有当前行`、状态不变。

### 11.1 `i <文本>`

- 在当前行**之后**插入一个新的数据结点，**新行成为当前行**（指导书 规则 1）。
- 空文档：插入为第一行并成为当前行（规则 1 明确允许插入创建第一行）。
- 文本为空（只敲 `i`，或 `i` 后只有一个分隔空格）→ 插入**空行**，合法（空行是结点，不是"没有内容"，C3）。
- 成文：输出 `当前行：<新行号>`。

### 11.2 `d`

- 删除当前行；删除后新当前行的选择（指导书 规则 2，冻结）：
  1. 优先取删除前的**下一行**；
  2. 没有下一行 → 取删除前的**上一行**；
  3. 都没有（删的是唯一一行）→ **无当前行**。
- 成文：`当前行：<新行号>`；文档被删空时为 `当前行：无`。
- 内存：被删结点不可再被访问；其行内容数组随结点一起释放（C5）。

### 11.3 `r <文本>`

- 只替换当前行的**内容**，当前行结点、结点 id 与行号均不变（规则 2 后半句 / A4）。
- 文本为空 → 替换为**空行**，合法。
- 成文：输出 `当前行：<行号>`。
- 内存：一律「先分配新数组 → 拷贝 → 成功后释放旧数组」（ROADMAP §4.1 C4），等长替换也走同一路径。

## 12. 提示文案总表（冻结，逐字一致）

| 场景 | 文案（stdout，一行，`\n` 结尾） |
| --- | --- |
| 空文档上执行依赖当前行的命令（`f` `l` `n` `u` `d` `r`） | `错误：空文档没有当前行` |
| 首行再执行 `u` | `错误：已经是第一行` |
| 末行再执行 `n` | `错误：已经是最后一行` |
| `g` 缺参数 | `错误：g 需要一个行号` |
| `g` 参数不是整数 | `错误：行号非法：<参数原样>` |
| `g` 行号越界 | `错误：行号超出范围：<n>（当前共 <m> 行）` |
| 未知命令 | `未知命令：<原样输入>（输入 h 查看帮助）` |
| 定位 / 插入 / 删除 / 替换成功 | `当前行：<行号>` 或 `当前行：无`（仅删除导致文档变空时） |

约定：错误行**不**前缀提示符；提示符 `> ` 在每条命令处理完之后的下一轮才输出（与 D1 一致）。

## 13. 当前行与不变量（D2-D5 验收锚点）

- **I3** 在每条命令后必须成立：`current == nullptr` ⇔ 链上没有数据结点；否则 `current` 必是链上数据结点。
- `i` 之后 **I1**/**I4** 成立：新结点与前后结点的 `prev`/`next` 互指正确，链仍无环。
- `d` 之后：被删结点不再可从链上到达；删到最后一行时 `head->next == tail` 且 `current == nullptr`。
- `r` 之后：结点地址与 `id` 不变、行号不变、内容为新文本、旧数组已释放（A4）。
- **失败路径**：只多一行错误提示，`p` 的输出逐字节不变（A2/A3）。

## 15. `/ <子串>` —— 从当前行向后查找

- 参数取命令字符之后至行尾的内容，去掉恰好一个分隔空格；其余字符原样保留。
- 查找串不能为空；空参数输出 `错误：查找串不能为空`，不改变状态。
- 区分大小写。从当前行第 1 列开始，按链表顺序查到文档末尾，不回绕到当前行之前。
- 命中时将该行设为当前行，并输出 `找到：第 <行号> 行，第 <列号> 列`；列号从 1 起。
- 未命中（含空文档）输出 `未找到：<查找串>`，文本与 current 均保持不变。

## 16. `s /旧串/新串/` —— 替换当前行内子串

- 参数语法严格为 `s /旧串/新串/`，恰有三个 `/`；不支持转义，旧串与新串均不能包含 `/`。
- 旧串不能为空，新串可以为空。缺少分隔符、缺少结尾 `/`、多余 `/`、空旧串均输出：

      错误：s 命令格式错误，应为 s /旧串/新串/（旧串不能为空）

- 只处理当前行，区分字节；从左到右替换所有不重叠匹配。每次命中后跳过整个旧串长度；只扫描原内容，新生成内容不会再次匹配。
- 先统计命中数与结果长度，再精确分配一次新数组；分配成功后才释放旧数组。无匹配时零分配，内容、current 与未保存标记均不变。
- 无匹配输出 `未找到可替换的子串：<旧串>`。命中后输出 `已替换 <次数> 处`，随后输出 `当前行：<当前行号>`；当前行结点与行号不变。
- 分配失败输出错误提示并保留原行内容。

## 17. `c` —— 统计

- 无参；尾随非空白字符按未知命令处理。
- 每次遍历链表重算，输出 `共 <行数> 行，<字符数> 个字符`。
- 字符数为所有数据结点内容长度之和；不含行结束符与结尾 `\0`，空行贡献 0。

## 18. `e` —— 重新读入

- 始终重新读取启动参数中的**输入文件**，不是输出文件。
- 若存在未保存修改，先输出 `存在未保存的修改，确认重新读入？(y/n)：` 并等待下一行；去掉首尾空格和制表符后恰为小写 `y` 才继续，其它输入均取消，输出 `已取消重新读入`。
- 无未保存修改时直接执行。成功后用新文件整体替换旧链表，非空文档 current 指向第一行，空文档 current 为 nullptr；输出 `已重新读入 <行数> 行，<字符数> 个字符`，再输出 `当前行：<行号>` 或 `当前行：无`。
- 文件打不开输出 `错误：无法重新读入输入文件：<路径>`；读取失败输出 `错误：重新读入输入文件失败：<路径>`；内存不足输出 `错误：内存不足，重新读入失败：<路径>`。
- 任一失败都保留原链表、current 与未保存标记。

## 19. `w` —— 保存

- 无参；保存到启动参数中的输出文件。以二进制覆盖写入，按链表顺序输出每行内容并追加一个 LF；空文档输出 0 字节。
- 成功输出 `已保存到：<输出路径>` 并清除未保存标记。
- 无法打开输出文件输出 `错误：无法打开输出文件：<路径>`；写入或关闭失败输出 `错误：写入输出文件失败：<路径>`。失败时不输出成功提示，未保存标记保持不变。

## 20. 未保存标记、`q` 与内存计数

- 插入/删除，或实际改变文本的 `r` / `s` 会设置未保存标记；定位、查找、统计不改变标记。
- 成功 `e` 或 `w` 清除未保存标记；取消或失败的 `e` / `w` 保持标记。
- `q` 有未保存修改时输出 `存在未保存的修改，确认退出？(y/n)：`；只有下一行去除首尾空格和制表符后恰为小写 `y` 才退出，其它输入输出 `已取消退出` 并继续。
- stdin EOF 仍按退出处理；若此时有未保存修改，因没有可读取的确认输入，向 stderr 输出 `警告：输入结束，未保存的修改将丢失` 后退出。
- A11 计数器分别记录本程序直接拥有的 `char[]` 与数据结点分配/释放次数，不包含标准库内部临时对象。主循环结束、编辑器析构后比较两组计数；任一不平衡时 stderr 输出计数诊断并以退出码 5 结束。
- A11 的 5000+ 字符长行往返仍需按 ROADMAP §5/§6 验收；计数器本身不替代该项验证。

## 21. 可视化追踪扩展（选做）

- `--trace` 开启 NDJSON v1.0 追踪；可紧跟一个路径，不提供路径时写到输出文件同目录的 `trace.ndjson`。`--trace=off` 显式关闭；`--trace-buffer` 关闭每步 flush。追踪默认关闭。
- 每条记录包含一次完整操作后的真实链表快照。`nodes` 按 head→next 顺序写出，结点 `prev`/`next` 来自真实指针；`changed.relinked` 在对应的指针赋值位置记录。
- 删除历史在摘链前深拷贝，事件写出发生在内容与结点释放之后；前端仅读取 JSON，不访问编辑器内存。
- 追踪写入失败时向 stderr 输出警告并关闭追踪，编辑器继续运行。追踪启用或关闭均不改变基础命令的 stdout 与输出文件内容。
- `x` 无参。追踪启用时追加一个 `snapshot` step 到当前 trace；追踪关闭时覆盖生成输出文件同目录的单步 `trace.ndjson`。失败只提示，不改变链表。
- 浏览器打开 `viz/index.html` 后通过 File API 选择 trace 文件。页面可单步/连续回放、前后对照、查看完整结点表与原始 JSON；超过 60 个数据结点时画布显示当前行附近的 next 链窗口。
